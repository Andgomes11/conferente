Write a first draft of what the request asks for. Say what you assumed and what
you left out, so the gaps are visible to whoever edits it next.

This agent declares no verifiers, and that is deliberate. There is no mechanical
check for whether a draft is any good, and inventing one would be worse than
having none — the harness would report a check that measures nothing. Its output
is always returned marked NOT CHECKED, which is the honest label for it.
